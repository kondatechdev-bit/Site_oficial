# Estrutura de Imagens & Marcas - Konda Tech

Esta pasta contém os recursos visuais, logótipos e marcas de todos os projetos do ecossistema Konda Tech.

## Estrutura de Diretórios

- `/images/logos/`: Logótipos oficiais em formato SVG e PNG.
  - `konda-tech-logo.svg` -> Marca principal da Konda Tech
  - `silvia-ai-logo.svg` -> Logótipo do projeto SILVIA (IA)
  - `aetheria-craft-logo.svg` -> Logótipo do jogo Aetheria Craft (306d)
  - `konda-freelas-logo.svg` -> Logótipo do marketplace Konda Freelas (200d)
  - `konda-store-logo.svg` -> Logótipo do Konda Store
  - `konda-manager-logo.svg` -> Logótipo do Konda Manager SaaS

- `/images/payments/`: Marcas e logótipos dos canais de apoio financeiro e IBANs.
  - `multicaixa-express.svg` -> Multicaixa Express
  - `bai.svg` -> Banco Angolano de Investimentos
  - `bfa.svg` -> Banco de Fomento Angola
  - `bic.svg` -> Banco BIC
  - `atlantico.svg` -> Banco Millennium Atlântico
  - `sol.svg` -> Banco SOL
  - `paypal.svg` -> PayPal
  - `binance.svg` -> Binance & Binance Pay
  - `airtm.svg` -> Airtm
  - `unitel-money.svg` -> Unitel Money
  - `afrimoney.svg` -> Afrimoney
  - `aki.svg` -> AKI Pagamentos

- `/images/projects/`: Mockups e pré-visualizações visuais dos projetos.
  - `silvia-preview.svg`
  - `aetheria-preview.svg`
  - `freelas-preview.svg`
  - `store-preview.svg`

## Instruções para Substituição
Para substituir qualquer imagem por uma versão customizada em PNG/JPG/SVG, basta colocar o arquivo correspondente na pasta indicada mantendo o nome de referência.
